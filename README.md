# 古船模型帆索校准 · 索路装配校验台

零依赖 Node.js（仅内置模块）的小应用。包含两部分：

- `/` 模型帆索校准：模型建档、帆索任务、松紧状态与调整记录。
- `/rig` **索路装配校验台**：按船登记桅杆 / 滑轮 / 系点 / 接头，并校验每条帆索的有向索路。

## 运行

```bash
npm start          # http://localhost:3038
```

可选环境变量：`PORT`（端口）、`DB_PATH`（数据文件位置，便于隔离测试）。

数据保存在 `data/model-rigging-calibration.json`，原子写入（临时文件 + rename），
重启后数据仍在。旧数据首次启动时会自动迁移，为每艘船补齐索路结构与一套示例索路。

**并发安全与故障原子性**：进程内只加载一份“已提交”数据，所有写入经串行队列
“读-改-写”，且变更在已提交数据的**深克隆**上进行：`saveDb` 成功（临时文件 + rename）
后才把克隆发布为新的已提交内存并返回成功响应。因此：

- 并发登记不会丢记录，也不会因争抢临时文件产生服务端错误；
- **保存失败时整体回滚**——内存维持提交前状态（后续读取看不到未落盘数据，重启也
  一致），失败响应不留下任何部分记录；
- 成功响应一定对应已经落盘的数据。

## 校验规则（七类问题）

每条帆索填写有向的 **起点 → 经过节点（有序）→ 终点** 和**必填**的目标桅区，系统标出 **索位与原因**：

| 类型 | 含义 |
| --- | --- |
| `dangling` 悬空端点 | 起点 / 终点 / 经过节点编号未在本船登记 |
| `repeated` 重复经过 | 索路中同一节点出现多次 |
| `cross_mast` 跨桅错接 | 相邻节点分属不同桅区 |
| `unlinked` 连接未登记 | 索路的**每一段**相邻连接都必须在“允许连接关系”中登记；起点没有出向登记、或中途/末段缺连接同样阻断 |
| `joint_mismatch` 接头不匹配 | 相邻接头型号不一致，或接头侧连接未登记在“允许连接关系”中 |
| `reversed` 起终点倒置 | 起点为系点而终点为桅杆/滑轮（受力方向倒置），或起终点均为系点 |
| `wrong_zone` 未回到目标桅区 | 目标桅区为空（提交时直接 400 拒收），或终点所在桅区 ≠ 目标桅区 |

校验台页面按船显示：

- **索路图**：SVG 按桅区布列节点，灰色虚线为允许连接关系，彩色有向箭头为索路；
  有阻断问题的索路画成红色。
- **阻断清单**：每条不合格索路列出问题标签、索位（索名）、节点位置与原因。
- **可装配状态**：全部索路通过 → “可装配”，否则显示“阻断 · N / M”。
- **按问题筛选**：点击问题类型标签即可只看该类问题。

调整一条索路只改对应船（数据按船隔离）；**提交失败（4xx）时表单中的路径与页面状态
保持不动**，仅显示错误提示，服务端不写盘。

## 测试（真实浏览器）

使用 Playwright + Chromium（共 23 项，两个项目共用同一浏览器），在真实浏览器中走通：
一条完全正确的索路、七类错误逐一触发（含缺出向连接/缺后段连接）、按问题筛选、跨船
隔离、提交失败时路径与状态不动、目标桅区为空被拒收且不写盘、另起进程重启后数据仍在；
并通过 API 验证并发登记不丢记录、无 5xx、成功响应与落盘一致。另有专门的**保存失败
故障组**（独立服务进程，`ENABLE_FAULTS=1` 注入磁盘写失败）：验证 500 后接口、内存、
页面、磁盘与重启结果一致，失败数据不残留，且故障恢复后写入正常。

```bash
npm ci             # 按锁文件安装依赖
npm test           # 自动准备浏览器（含无 root 方案）后运行全部用例
```

> 故障注入端点 `/api/test/faults` 仅在环境变量 `ENABLE_FAULTS=1` 时存在，正常
> `npm start` 下返回 404，不影响生产行为。

`npm test` 会先执行 `scripts/setup-browser.sh`：

1. `npx playwright install chromium` 下载浏览器；
2. 若系统缺少浏览器动态库且没有 root（无法 apt 安装），以普通用户下载对应 `.deb`
   解包到项目内 `.pw-libs/`，测试经 `LD_LIBRARY_PATH` 加载；
3. 若系统无中文字体，把文泉驿正黑装到 `~/.fonts/`。

该脚本可重复执行；已具备所需库/字体时会自动跳过。
